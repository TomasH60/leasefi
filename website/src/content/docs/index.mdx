If you run both sides of the lab, complete the **provider setup first**, then follow
the tenant path from another machine. Tenants using an existing provider can start
with the tenant path directly.

The walkthrough keeps the detailed commands for the cluster, wallet, certificate,
networking, and SSH container together in numbered chapters. Each step tells you
which machine to use and what to verify before continuing.

Once the environment is ready, LeaseFi takes over tenant funding, deployment
creation, bid selection, manifest upload, monitoring, and cleanup. It does not
install Kubernetes, run the provider service, or configure host networking.

:::note[Lab scope and development status]
The setup walkthrough uses the public Akash `sandbox-2` chain with a locally hosted
Linux provider. It is not a production provider installation guide.
LeaseFi is under active development; live end-to-end tenant validation is still
required. The Sepolia → Osmosis bridge walkthrough is a separate test and does not
fund an Akash sandbox deployment.
:::
